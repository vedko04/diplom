# Eye Tracking — исследование пользовательского поведения

Веб-приложение для исследования пользовательского поведения в WEB-интерфейсах с использованием технологий видеоокулографии (eye tracking).

Проект разработан в рамках выпускной квалификационной работы и предназначен для получения и анализа данных о движении взгляда пользователя во время взаимодействия с веб-интерфейсом.

## Возможности

* калибровка системы отслеживания взгляда;
* отслеживание положения взгляда пользователя в реальном времени;
* сбор данных о движении глаз;
* визуализация внимания пользователя;
* построение тепловых карт (heatmap);
* анализ взаимодействия пользователя с элементами интерфейса;
* проведение UX-исследований на основе объективных данных о движении взгляда.

## Технологии

* **React** — разработка пользовательского интерфейса;
* **TypeScript** — типизация приложения;
* **Vite** — сборка и dev-сервер;
* **WebGazer.js** — отслеживание направления взгляда пользователя;
* **MediaPipe** — обработка данных, связанных с лицом и положением глаз;
* **CSS** — стилизация интерфейса.

## Архитектура приложения

Основной пользовательский сценарий состоит из нескольких этапов:

1. Авторизация пользователя.
2. Калибровка системы eye tracking.
3. Проведение исследования.
4. Сбор данных о движении взгляда.
5. Визуализация результатов.
6. Анализ полученных данных.

## Калибровка

Перед началом исследования пользователь проходит калибровку системы. На экране последовательно отображаются контрольные точки, на которые необходимо направлять взгляд.

Полученные данные используются для повышения точности определения положения взгляда пользователя.

## Визуализация

Одним из основных результатов исследования является тепловая карта, позволяющая определить области интерфейса, привлекающие наибольшее внимание пользователя.

Такая визуализация может использоваться для оценки:

* эффективности расположения элементов интерфейса;
* визуальной иерархии страницы;
* заметности отдельных элементов;
* поведения пользователя при взаимодействии с интерфейсом;
* потенциальных проблем UX.

## Запуск проекта

```bash
git clone https://github.com/vedko04/diplom.git

cd diplom

npm install

npm run dev
```

После запуска приложение будет доступно по адресу, указанному Vite в терминале.

## Назначение проекта

Проект предназначен для исследования возможностей применения технологий eye tracking при анализе пользовательского поведения в WEB-интерфейсах.

Полученные данные могут использоваться в UX/UI-исследованиях и при принятии решений по улучшению пользовательского опыта.
